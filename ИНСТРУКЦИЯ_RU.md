# Макропад: 3 кнопки + EC11 + nRF52840 (nice!nano v2 compatible)

**Это исходники ZMK для сборки тестовой прошивки, а не готовый `.uf2`.**
Контроллер-клон нужно проверить: схема рассчитана на **распиновку nice!nano v2 / Pro Micro** и на совместимый UF2-загрузчик.

## Важные правила

1. Пока **НЕ подключай ни один аккумулятор**. Всё тестируем при питании контроллера по USB.
2. Если контроллер из коробки мигает выходами раз в секунду, **сначала перепрошей его, потом подключай свичи и EC11**.
3. Не соединяй контакты батареи B+ и B- между собой. Не путай их с `GND` или GPIO.
4. Провода подключаем к маркировкам на **твоей реальной плате**. Если надписи другие, не угадывать — сначала сверить фото обеих сторон с pinout.
5. Если у платы нет припаянных пинов, провода к площадкам нужно припаять. Дюпон без контакта не удержится.
6. Клон может оказаться несовместимым с ожидаемым загрузчиком/распиновкой; до успешной прошивки не подключай батарею.

## 1. Как работает тест

- Свич 1 => A (латинская A)
- Свич 2 => B
- Свич 3 => C
- Нажатие EC11 => Play/Pause
- Поворот EC11 по часовой стрелке => громче
- Поворот EC11 против часовой стрелки => тише

## 2. Подключение (всё при ВЫКЛЮЧЕННОМ USB)

**Внимание к подписям!** В прошивке используются номера контактов Pro Micro `D2…D7`, но на клоне nice!nano нередко нанесены **цифры от Nordic GPIO**, например `017`, `020`, `022`.

| Пин в инструкции | GPIO nRF52840 | Возможная подпись на клоне |
|---|---|---|
| D2 | P0.17 | `017` |
| D3 | P0.20 | `020` |
| D4 | P0.22 | `022` |
| D5 | P0.24 | `024` |
| D6 | P1.00 | `100` |
| D7 | P0.11 | `011` |

Точная маркировка твоей платы должна совпасть с распиновкой nice!nano v2 — для клона проверяем фотографию обеих сторон, прежде чем паять. **D2 не означает площадку с цифрой `002`!** Не путать с полярностью аккумулятора.

| Деталь | Первый контакт | Второй контакт |
|---|---|---|
| Свич 1 | D2 / 2 | GND |
| Свич 2 | D3 / 3 | GND |
| Свич 3 | D4 / 4 | GND |
| Нажатие EC11 (группа 2 выводов) | D5 / 5 | GND |
| Вращение EC11, группа 3 выводов | внешний A -> D6 / 6 | внешний B -> D7 / 7 |
| Вращение EC11, СРЕДНИЙ из группы 3 | GND | — |

**Обычный голый EC11 имеет группу из 3 контактов (вращение) и отдельную группу из 2 контактов (нажатие).** У группы из 3 средний контакт обычно общий C: его подключаем к `GND`, крайние — к D6 и D7. У отдельной группы из 2 контактов один — к D5, другой — к GND. Если EC11 уже установлен на платке-модуле с подписями `CLK`, `DT`, `SW`, `+`, `GND`, тогда: `CLK -> D6`, `DT -> D7`, `SW -> D5`, `GND -> GND`. Вывод `+` для подтяжек в нашей схеме не нужен; на неизвестном модуле сначала нужно проверить схему, **НЕ подавать 5 В на GPIO nRF52840 (они 3,3 В)**.

**Ни один из GPIO не соединяем с VCC/3V3 напрямую.** Все кнопки и контакты энкодера размыкают/замыкают вход на GND; в прошивке включены внутренние подтягивающие резисторы.

Если крутилка работает в обратную сторону, поменять местами A/B (D6/D7), когда USB отключён.

## 3. Как собрать .uf2 через GitHub без установки программ для компиляции

Простой путь с GitHub Desktop:

1. Зарегистрируйся на https://github.com, если учётной записи нет.
2. Установи **GitHub Desktop** с https://desktop.github.com.
3. Распакуй ZIP. Внутри папки лежат `build.yaml`, `config/`, `boards/`, `zephyr/`, `.github/` — **не удаляй папку `.github`**.
4. В GitHub Desktop: **File -> Add local repository -> Choose...**, выбери распакованную папку. Если появится предложение создать репозиторий здесь, нажми **Create a repository here**.
5. В нижней части GitHub Desktop заполни Summary, например `first firmware`, нажми **Commit to main**, затем **Publish repository**. Публичным делать не обязательно: можно выбрать private.
6. Открой репозиторий на github.com, вкладка **Actions**. Если GitHub попросит разрешить workflow, разреши. Дождись сборки **Build ZMK macropad firmware** (она может занимать несколько минут).
7. Открой успешную сборку (зелёная галочка), внизу блока **Artifacts** скачай `firmware` (ZIP). Распакуй; внутри ожидается `macropad-3keys-ec11.uf2`.
8. Если сборка красная — **не прошивай ничего**. Открой логи задачи Build, скопируй текст первой ошибки и пришли его.

В проекте используется ZMK **v0.3** и цель сборки `nice_nano_v2`, это стабильная схема из официального шаблона ZMK. Исходники подготовлены, но сборка и работа на твоём клоне здесь не проверялись.

## 4. Как залить на контроллер

1. Временно оставь плату **без кнопок, энкодера и аккумулятора**.
2. Подключи USB-C к компьютеру.
3. Два раза быстро (в пределах ~0,5 секунды) кратко замкни **RST на GND** (или дважды нажми Reset, если кнопка есть). **Не замыкай другие контакты, особенно B+ и B-.**
4. Если загрузчик совместим с nice!nano v2, появится съёмный диск, часто с названием `NICENANO` или похожим.
5. Перенеси на этот диск `.uf2`. Он может автоматически исчезнуть — это обычно означает перезагрузку.
6. Отключи USB. Теперь, при отключённом питании, подключай провода по таблице.
7. Снова подключи USB к компьютеру и проверь кнопки в блокноте: при подключённом USB ZMK обычно отдаёт события по USB.
8. Для проверки **Bluetooth отдельно от USB** отключи USB от компьютера и подай 5 В через USB-C **от зарядного адаптера или пауэрбанка** (без USB-подключения данных к ПК). Затем найди **Mini Macro EC11** в настройках Bluetooth ПК или iPad, подключи его и проверь кнопки.

### Если съёмного диска нет

Причины: кабель не передаёт данные; Reset работает иначе; не тот пин; загрузчик отличается. Не пытайся прошивать случайным файлом под другой контроллер. Пришли фото платы (обе стороны), что появилось на компьютере и какая ОС.

## 5. Если сборка прошла, но кнопки не работают

1. Проверить, что одна сторона каждого свича действительно соединена с GND, а другая с нужным D-пином.
2. На механическом свиче используются **два электрических контакта**; дополнительные пластиковые штырьки не являются контактами.
3. Если EC11 не реагирует — проверь, что средний вывод группы из 3 подключён к GND.
4. У разных EC11 разное число импульсов; в файле `boards/shields/tiny_macropad/tiny_macropad.overlay` можно поменять `steps = <20>;` и `triggers-per-rotation = <20>;` после проверки реального энкодера.
5. Если вращение меняет громкость наоборот, переставить провода D6 и D7 местами при отключённом USB.
6. Если Windows/iPad не видят Bluetooth, сначала проверь, что USB-клавиатура определяется и `.uf2` был прошит; затем удали старую пару Bluetooth и попробуй найти устройство заново.

## 6. Как поменять кнопки позднее

Открой `config/tiny_macropad.keymap`. Строка `bindings = <&kp A &kp B &kp C &kp C_PP>;` — это три кнопки и нажатие EC11. Например, `&kp Z` означает клавишу Z, `&kp LC(Z)` — Ctrl+Z. После изменения сохрани, сделай Commit/Push и скачай новый `.uf2`. ZMK умеет и другие сочетания/слои. Конфиг для будущих 9 кнопок сделаем, когда они придут.
